# Khushi Store Annual Sales Analysis 📊

## 📌 Project Overview

This project presents an **Annual Sales Analysis of Khushi Store** using Microsoft Excel. The project analyzes sales and order data to identify important business insights related to customers, sales channels, order status, states, gender, and overall sales performance.

The analysis is presented through an interactive and easy-to-understand **Excel dashboard**.

## 🎯 Objectives

* Analyze annual sales and order performance.
* Identify top-performing states.
* Understand customer demographics.
* Analyze sales based on gender.
* Compare different sales channels.
* Analyze order status and delivery performance.
* Identify useful business trends from the sales data.
* Present the findings through an interactive dashboard.

* Monthly sales trends.
